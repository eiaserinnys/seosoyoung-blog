## 3줄 요약

1. Windsurf 프로덕트 리드 Kevin Hou가 AI Engineer World's Fair에서 발표.
2. Windsurf의 핵심 차별점: Shared Timeline, 3가지 컨텍스트 카테고리, 자체 SE 모델 SU1, Data Flywheel.
3. Tool Specific 시리즈 26번째 영상으로, Windsurf의 제품 철학을 전면에 드러낸다.

## Shared Timeline

사용자와 AI의 모든 행위를 하나의 타임라인에 기록:

- 코드 편집, 터미널 명령, 파일 탐색 등 모든 액션을 추적
- AI가 사용자의 최근 컨텍스트를 실시간으로 파악
- "내가 뭘 하고 있었는지" 설명 불필요

## 3가지 컨텍스트 카테고리

- **Explicit**: 사용자가 명시적으로 제공한 정보
- **Implicit**: 열린 파일, 커서 위치 등에서 추론
- **Derived**: 코드 분석, 의존성 그래프에서 도출

## Data Flywheel + SU1 모델

- 사용 데이터가 쌓일수록 모델 품질 향상
- 자체 SE(소프트웨어 엔지니어링) 특화 모델 SU1 학습

## 가장 흥미로운 지점

Shared Timeline이 다른 도구에 없는 독특한 접근이다. 컨텍스트를 '주는 것'이 아니라 '관찰하는 것'으로 전환한 설계 결정.
