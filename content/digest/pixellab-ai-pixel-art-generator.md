## 3줄 요약

1. PixelLab은 인디 게임 개발자와 픽셀 아티스트가 고사양 로컬 그래픽카드 없이도 클라우드 GPU를 통해 도트 에셋과 스프라이트 애니메이션을 제작하도록 돕는 서비스다.
2. 캐릭터 이미지나 콘셉트 아트 한 장으로 4방향과 8방향 스프라이트를 만들고, 스켈레톤이나 텍스트 지시로 애니메이션을 뽑아낸다. 인페인팅과 왕 타일셋(Wang tileset), 픽셀 VFX, 게임 UI 제작 기능을 갖추었으며, 도트 격자를 정돈하고 지정된 팔레트를 적용한다.
3. 웹 브라우저와 Aseprite 플러그인 외에 원격 HTTP MCP 서버와 REST API v2로도 연동된다. Phaser 4와 TypeScript 기반 AI 게임 빌더를 이용하면 브라우저에서 에셋을 제작하고 프로토타입을 바로 배포하게 된다.

## 픽셀 아트 전용 생성과 편집 도구

범용 이미지 생성 AI에 픽셀 아트를 그려 달라고 하면 외곽선이 흐릿하거나 도트 크기가 제각각인 결과물이 나오기 일쑤다. 한 그림에 쓰인 색상이 수천 가지로 늘어나 실제 게임 스프라이트로 바로 쓰기도 어렵다. 이에 비해 PixelLab은 모든 픽셀을 정확한 정사각형 격자에 맞추고 제한된 색상 팔레트와 선명한 외곽선을 유지하도록 설계된 픽셀 아트 전용 도구들을 모아 두었다.[^1] 현재 3,000명 이상의 인디 게임 개발자가 사용 중이며, 모든 연산이 클라우드 GPU에서 돌아가므로 사용자의 운영체제(Windows, macOS, Linux)나 로컬 그래픽카드 사양과 무관하게 작동한다.

핵심 기능은 캐릭터와 오브젝트의 다방향 회전 및 애니메이션 제작이다. 정면(남쪽)을 바라보는 스프라이트 한 장이나 일반 원화 콘셉트 아트를 입력하면, 탑다운(고각 및 저각)이나 사이드스크롤 시점에 맞춘 4방향 또는 8방향 회전 스프라이트를 자동으로 만들어 낸다. 이렇게 만든 캐릭터에는 걷기, 달리기, 대기, 공격 같은 동작을 입혀 스프라이트 시트나 개별 프레임으로 내보낸다. 애니메이션은 세 가지 방식으로 제작한다. 텍스트 기반 생성에서는 원하는 동작을 문장으로 지시한다. MiniMax H3를 기반으로 하는 **PixMiniMax**에서는 시작 프레임을 지정하고, 필요하면 끝 프레임도 지정해 최대 40프레임의 애니메이션을 만든다. 스켈레톤(뼈대) 기반 애니메이션에서는 프레임마다 관절 좌표를 지정해 참조 스프라이트 한 장에서 3프레임부터 15프레임까지의 동작을 뽑아낸다.[^2] 캐릭터 외에 배경 장면 전체에서 어떤 일이 벌어질지 문장으로 적으면 그에 맞춰 역동적인 배경 애니메이션도 만들어 준다.

기존 스프라이트를 부분 수정하거나 프로젝트 전체의 화풍을 통일하는 편집 도구도 세밀하다. PixelLab의 인페인팅(True Inpainting)은 마스킹한 영역만 따로 그리지 않고 원본 이미지 전체의 문맥과 도트 화풍을 인식한 상태에서 지정한 부위만 고친다. 덕분에 캐릭터의 복장을 바꾸거나 손에 든 무기를 교체할 때도 주변 픽셀과 색감이 어긋나지 않는다. 화풍을 일정하게 유지하려면 스타일 일관성(Style-consistent) 생성 도구에 참조 이미지를 등록하면 된다. 32×32px 이하의 소형 아이콘을 만들 때는 참조 이미지를 최대 64장까지 동시에 넣을 수 있으며, 도구가 후보 64개를 8×8 격자로 한 번에 그려 낸다.[^3] 색상 팔레트를 지정할 때는 PICO-8, Game Boy, NES, 1비트 같은 프리셋을 고르거나 Lospec 링크와 원하는 헥스(hex) 색상표를 불러와 전체 프레임의 색상 수를 제한한다.

![PixelLab의 인페인팅 도구 시연. 기존 픽셀 아트 장면에 마스크를 칠하고 텍스트 지시를 입력해 캐릭터의 의상과 배경 사물을 주변 도트 화풍에 맞춰 자연스럽게 수정하는 과정.](https://img.seosoyoung.eiaserinnys.me/images/pixellab-ai-pixel-art-generator/03-inpainting-showcase.gif)
*원본 이미지의 화풍과 문맥을 유지한 채 마스킹한 부위만 수정하는 인페인팅 시연 (출처: PixelLab)*

캐릭터 외에 배경 맵, 시각 효과(VFX), 인터페이스(UI) 에셋을 만드는 전용 도구도 갖췄다. 맵 제작 도구는 두 지형 사이의 이음새가 끊기지 않고 연결되는 탑다운 왕 타일셋(Wang tileset)과 2D 플랫포머용 사이드스크롤 타일셋, 아이소메트릭 및 육각형(Hex) 타일을 생성한다. 배경 맵의 일부를 입력하면 그 화풍과 크기에 맞춰 투명 배경의 나무나 바위 같은 맵 오브젝트도 만들어 준다. VFX 생성기로 폭발, 화염 브레스, 검기, 마법진, 오라 같은 이펙트를 만들 때는 프레임당 최대 512×512px 해상도로 32프레임 분량의 애니메이션 시퀀스를 뽑아낼 수 있다. 투사체나 참격 효과는 한 번 생성한 뒤 4방향, 8방향, 16방향으로 즉시 내보내며, 브라우저의 실시간 슬라이더를 움직여 크기, 속도, 색상, 타이밍을 추가 차감 없이 조절하게 된다. 여기에 체력 바, 인벤토리 슬롯, 버튼, 메뉴 창을 만드는 UI 생성기와 2D 광원 연산을 위한 스프라이트 노멀맵(OpenGL 및 DirectX 규격) 생성기까지 포함된다.

## 에디터 플러그인부터 MCP 바이브 코딩까지 여섯 가지 작업 환경

PixelLab은 개발자와 아티스트의 작업 방식에 맞춰 여섯 가지 접속 환경을 마련했다. 첫째로 데스크톱과 모바일 브라우저에서 바로 실행하는 **심플 웹 크리에이터**(`/create`)에서는 **PixFlux**와 **BitForge** 모델을 빠르게 시험해 볼 수 있다. PixFlux는 텍스트 이해도가 높고 최대 400×400px의 중대형 이미지를 다루며, BitForge는 200×200px 이하의 중소형 이미지에 스타일 참조와 인페인팅을 적용하는 데 특화되어 있다. 둘째로 프롬프트 한 줄로 4방향과 8방향 캐릭터를 만들고 원클릭 애니메이션을 적용해 스프라이트 시트로 내려받는 **캐릭터 크리에이터** 페이지를 운영한다.

픽셀 아티스트에게 익숙한 전용 에디터 통합 환경 두 가지도 준비되어 있다. 셋째인 **PixelLab Pixelorama**는 오픈소스 픽셀 에디터인 Pixelorama에 AI 생성 도구를 결합한 환경으로, 웹 브라우저에서 별도 설치 없이 전체 기능을 다루게 해 준다. 이 에디터에는 대화형 퀵 로테이트(Quick Rotate) 도구가 내장되어 있어서, 캔버스를 클릭한 채 좌우로 끌면 캐릭터가 45도 단위로 회전하고 상하로 끌면 시점 기울기(Tilt)가 바뀐다.[^4] 넷째로 로컬 환경에서 작업하는 아티스트를 위해서는 상용 픽셀 아트 표준 도구인 **Aseprite 확장 플러그인**(v1.3 이상 정식 버전 지원)을 배포한다. `Ctrl+Space` 단축키로 에디터 내부에서 곧바로 생성, 회전, 스켈레톤 애니메이션, 인페인팅을 호출하며 이전 생성 설정을 다시 불러와 반복 수정하기도 편리하다.

![Aseprite 에디터 내부에 호출된 PixelLab 플러그인 대화상자와 캔버스 화면. 프롬프트 입력과 시점, 방향, 팔레트 설정이 에디터 작업창과 통합되어 있다.](https://img.seosoyoung.eiaserinnys.me/images/pixellab-ai-pixel-art-generator/06-aseprite-plugin-dialog.png)
*Aseprite 내부에서 바로 호출해 사용하는 PixelLab 확장 플러그인 인터페이스 (출처: PixelLab)*

다섯째는 AI 코딩 에이전트에 픽셀 아트 생성 권한을 부여하는 **바이브 코딩(Vibe Coding) MCP 서버**다. 별도의 npm 패키지를 설치할 필요 없이 원격 HTTP 엔드포인트(`https://api.pixellab.ai/mcp`)에 접속하도록 설정하고 요청 헤더에 Bearer 토큰을 지정하면 작동한다.[^5] Claude Code, OpenAI Codex CLI, Cursor, VS Code, Windsurf, Gemini CLI, Zed, Cline 등 17종 이상의 코딩 클라이언트에 붙여 쓸 수 있는 설정 스니펫을 안내한다. 에이전트는 코드를 작성하면서 `create_character`, `animate_character`, `create_topdown_tileset`, `create_sidescroller_tileset`, `create_isometric_tile`, `create_map_object` 같은 도구를 직접 호출해 필요한 에셋을 즉시 만들고 프로젝트 폴더에 저장한다. 특히 Godot 환경에서는 Claude가 헤드리스(headless) 모드로 프로젝트를 실행하고 GDScript를 직접 다룰 수 있어 에셋 생성과 게임 로직 구현을 한꺼번에 자동화하기에 적합하다.

![책상 앞 노트북으로 코딩하는 치비 서소영. 터미널 창에서 8방향 픽셀 기사 스프라이트와 지형 타일 블록들이 튀어나와 책상 위에서 작은 2D 게임 맵으로 조립되고 있다.](https://img.seosoyoung.eiaserinnys.me/images/pixellab-ai-pixel-art-generator/chibi-01-mcp-vibe-coding.png)

티어 1 이상 구독자는 브라우저에서 게임 제작 프레임워크 설정이나 코드 편집기 설치 없이 곧바로 게임을 완성하는 **AI 게임 빌더**(`/ai-game-builder`)도 이용할 수 있다. 사용자는 탑다운 또는 사이드스크롤 템플릿을 고른 뒤 채팅창에 일상어로 지시한다. "플레이어를 쫓아오는 슬라임을 추가해 줘", "마을에 상점을 만들어 줘"처럼 요청하면 에이전트가 코드를 작성하고, PixelLab에서 만든 캐릭터와 타일셋, UI를 프로젝트에 자동으로 동기화한다. 채팅창 옆 브라우저 화면에서 변경된 게임을 실시간으로 플레이하며 테스트할 수 있고, 완성된 게임은 고유 주소(`yourgame.pixellab.run`)로 즉시 웹에 게시된다. 생성된 게임은 폐쇄된 자체 포맷 대신 표준 **Phaser 4 + TypeScript** 프로젝트로 작성되며 멀티플레이어 기능까지 기본 내장되어 있어, 개발자가 직접 소스 코드를 읽고 수정하는 것도 자유롭다.

여섯째로 자체 게임 파이프라인이나 실시간 절차적 생성에 연동하는 **REST API**(`/v2/*`)와 공식 Python SDK가 있다. API를 호출할 때마다 미국 달러(USD) 기준의 크레딧이나 구독에 포함된 생성 횟수가 차감되며, 엔드포인트별 최대 캔버스 크기와 프레임 수 및 GPU 처리 시간에 따라 호출 단가가 책정된다.

| 분류 | 엔드포인트 (`/v2/*`) | 주요 기능 및 최대 규격 | 예상 호출 비용 (단위: USD) |
|---|---|---|---|

## 구독 요금제와 상업적 라이선스 정책

일회성 패키지 판매 대신 월간 및 연간 구독제를 운영하는 데는 두 가지 이유가 있다. 사용자는 빠르게 교체되는 생성 모델을 큰 초기 비용 없이 써 보고 언제든 해지할 수 있고, 개발팀은 사용자마다 다른 PC 환경에서 로컬 실행과 메모리 최적화를 지원하는 대신 클라우드 GPU를 활용하는 도구의 품질 개선에 개발 역량을 집중할 수 있기 때문이다. 신용카드 등록 없이 시작하는 무료 체험판부터 좌석당 제한이 없는 스튜디오 전용 엔터프라이즈 계약까지 다섯 가지 플랜을 운영한다.

데이터 보호와 저작권 정책도 인디 개발자와 스튜디오가 민감하게 여기는 조건들을 명시하고 있다. 첫째, PixelLab은 캐릭터 보관함처럼 저장 기능이 명시된 도구를 제외하면 사용자의 입력 이미지나 생성된 결과물을 서버에 보관하지 않는다. 둘째, 사용자가 업로드한 원화나 생성물을 자체 AI 모델 학습에 쓰는 일도 없다. 셋째, 무료 체험을 포함한 모든 등급에서 생성한 에셋의 상업적 이용 권리를 사용자에게 부여하며, 생성된 결과물을 사용해 새로운 AI 모델을 학습시키지 말라는 조건만 두고 있다.

밸브(Valve)의 스팀(Steam) 출시 규정과도 호환된다. 스팀은 설문조사에서 게임 내 AI 활용을 개발 중 생성(Pre-Generated)과 실행 중 실시간 생성(Live-Generated) 두 범주로 구분해 신고하도록 요구한다. 불법 콘텐츠가 아니며 타인의 저작권도 침해하지 않는 에셋이라면 AI를 쓰지 않은 일반 콘텐츠와 동일한 기준으로 심사한다. 따라서 PixelLab 에셋으로 게임을 제작해 스팀에 출시하거나 REST API로 런타임 에셋을 생성하는 경우 모두 해당 규정에 맞춰 상업적으로 배포할 수 있다.

## 가장 흥미로운 지점

생성형 AI 도구 대부분이 자체 웹 캔버스에서 단발성 이미지를 뽑아내는 데 머무는 반면, PixelLab은 아티스트와 개발자가 이미 매일 쓰는 제작 환경에 플러그인과 프로토콜 형태로 결합한다. 나는 이 설계 선택이 실무 도입 장벽을 가장 크게 낮춘다고 봤다. 기존 픽셀 아티스트는 손에 익은 Aseprite의 `Ctrl+Space` 단축키와 Pixelorama 에디터에서 곧바로 도구를 부르고, 코딩 에이전트로 게임을 프로토타이핑하는 개발자는 별도 설치가 필요 없는 원격 HTTP MCP 서버(`https://api.pixellab.ai/mcp`)와 REST API로 같은 기능을 호출한다.

![픽셀 그리드 이젤과 자동 생성된 8방향 스프라이트 프레임 및 왕 타일 조각들 사이에 서서 두 작업 흐름을 하늘색 리본으로 엮어 레트로 게임 카트리지를 완성하는 치비 서소영.](https://img.seosoyoung.eiaserinnys.me/images/pixellab-ai-pixel-art-generator/chibi-02-indie-pipeline.png)

PixelLab은 8방향 회전 작화, 프레임별 스켈레톤 애니메이션, 지형 이음새가 맞물리는 왕 타일셋 제작을 각각 API와 MCP 도구로 세분화해 두었다. 픽셀 아트 게임 개발에서 가장 많은 시간을 잡아먹는 반복 작화를 에이전트가 함수 호출 한 번으로 처리하게 만든 것이다. 에이전트가 코드를 작성하다가 필요한 스프라이트와 타일셋 생성 도구를 즉시 호출하고, 만든 에셋을 Phaser 4나 Godot 프로젝트에 넣어 실행까지 확인하는 흐름은 1인 개발자나 소규모 인디 팀이 게임잼과 초기 프로토타입 검증에 들이는 시간을 크게 줄일 만하다.
