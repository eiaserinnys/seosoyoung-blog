## 3줄 요약

1. 스탠퍼드 Hazy Research의 Vivien Cheng, Jerry Liu, Morris Yau, Chris Ré가 2026년 11월 25일 발표한 연구로, 8개 계열 12개 베이스 모델(1.5B\~27B 파라미터)을 대상으로 서로 다른 LLM의 내부 표현이 기하학적 유사성에 그치지 않고 실제로 호환되는지 검증했다.
2. 경사하강법 없이 5,000개 미만의 공유 사실에서 닫힌 형태로 계산한 회전 행렬($R$)과 단일 전역 스케일($s$)만으로 공여 모델의 사실 인출용 키(key) 은닉 상태를 변환해 수혜 모델에 대입했다. 그 결과 20개 모델 쌍에서 전이 정확도 중앙값 41%(자가 교체 정확도 중앙값 55% 대비 보존율 73%)를 기록했고, 세 모델을 거치는 연쇄 회전($A \to B \to C$)도 직접 회전 정확도의 중앙값 99%를 유지했다.
3. 수혜 모델이 가중치에 저장해 두고도 직접 프롬프트에서는 답하지 못하던 지식인 암흑 기억(dark memories)에 공여 모델의 회전된 키를 주입하자 18%가 정답으로 복원됐다. 사실 인출 실패의 상당수가 가중치의 지식 부재라기보다 불완전한 키 표현 때문에 생긴다는 점을 보였다.

## 기하학적 유사성에서 기능적 호환성으로: 키 은닉 상태 교체

플라톤적 표현 가설(Platonic Representation Hypothesis, PRH)[^prh]은 개별적으로 학습된 신경망들이 현실 세계에 대한 공통된 내부 표현으로 수렴한다고 본다. 선행 연구들은 서로 다른 모델이 기하학적으로 유사한 표현을 학습한다는 점을 확인했으나, 기하학적 유사성이 곧 표현의 상호 호환성(interchangeability)을 보장하지는 못한다. 스탠퍼드 Hazy Research는 경사하강법으로 추가 학습을 수행하지 않은 상태에서도 한 LLM이 다른 LLM의 은닉 상태를 자기 표현처럼 받아 사실 인출(factual recall) 과제를 풀 수 있는지 실험했다.

[^prh]: Huh et al. (2024), "The Platonic Representation Hypothesis", arXiv:2405.07987.

LLM의 사실 인출은 키-값 조회(key-value lookup) 메커니즘과 유사하게 작동한다.[^kv] 초기부터 중간까지의 레이어가 마지막 주어 토큰(예: "France")에서 키(key) 표현을 구성하면, 후기 레이어가 이 키를 사용해 가중치에 저장된 값(value, 예: "Paris")을 조회하는 구조다. 연구진은 최종 출력값 대신 중간 레이어의 **키 은닉 상태 단 하나**를 교체한 뒤, 은닉 상태를 받아 쓰는 수혜 모델(recipient LLM)의 후기 레이어가 자체 가중치에서 어떤 답을 인출하는지 측정했다.

[^kv]: Geva et al. (2021, arXiv:2012.14913), Meng et al. (2022, arXiv:2202.05262), Geva et al. (2023, arXiv:2304.14767). 트랜스포머의 피드포워드(MLP) 층을 키-값 메모리로 해석하는 선행 연구들이다.

예를 들어 수혜 모델에 "The capital of Germany is"를 입력하면 원래는 "Berlin"이라고 답한다. 이때 은닉 상태를 제공하는 공여 모델(donor LLM)에는 "The capital of France is"를 입력하고, "France" 토큰의 중간 레이어 은닉 상태를 추출한다. 여기에 회전과 스케일 변환만 적용해 수혜 모델의 "Germany" 은닉 상태와 교체하면, 수혜 모델의 답변이 "Berlin"에서 "Paris"로 바뀐다.

![공여 LLM에서 추출한 France 은닉 상태를 회전 및 스케일 변환해 수혜 LLM의 Germany 은닉 상태에 대입하면 출력이 Berlin에서 Paris로 바뀌는 과정](https://img.seosoyoung.eiaserinnys.me/images/platos-key/fig1-representation-swap.png)
*단일 은닉 상태 교체 실험(원문 Figure 1). (1) 공여 모델의 레이어 $\ell_A$에서 "France"의 은닉 상태를 추출하고, (2) 회전과 전역 스케일 변환을 거쳐 수혜 모델의 표현 공간으로 매핑한 뒤, (3) 수혜 모델의 레이어 $\ell_B$에서 "Germany"의 은닉 상태와 교체하면 수혜 모델이 "Paris"를 생성한다. 출처: Hazy Research*

## 닫힌 형태의 회전과 단일 전역 스케일: 20개 모델 쌍 실험

가중치가 고정된(frozen) 두 LLM 사이의 키를 정렬할 때는 직교 회전 행렬 하나와 단일 전역 스케일 계수만 사용한다. 이 변환은 두 모델이 모두 단독으로 정답을 맞히는 5,000개 미만의 학습 사실만으로 닫힌 형태(closed form)로 계산된다.

공여 모델 $A$와 수혜 모델 $B$에서 구한 학습 사실의 평균 키 벡터를 각각 $\mu_A, \mu_B$, 평균을 뺀 중심화 키 행렬(열 하나가 사실 하나의 키)을 $\tilde{Z}_A, \tilde{Z}_B$로 두면, thin SVD를 통해 직교 프로크루스테스(orthogonal Procrustes) 회전 행렬 $R$을 바로 계산할 수 있다. 전역 스케일 $s$는 수혜 모델의 전체 분산 규모에 맞추도록 프로베니우스 노름(Frobenius norm)의 비율로 정의했다.[^rotation-def]

$$\hat{z}_B = \mu_B + sR(z_A - \mu_A), \quad R = UV^\top \; (\tilde{Z}_B \tilde{Z}_A^\top = U\Sigma V^\top), \quad s = \frac{\|\tilde{Z}_B\|_F}{\|\tilde{Z}_A\|_F}$$

[^rotation-def]: 원문이 말하는 '회전(rotation)'에는 반사(reflections)도, 은닉 차원 크기가 서로 다른 모델 쌍 사이의 준직교 매핑(semi-orthogonal maps)도 포함된다.

| 항목 | 세부 구성 |
| :--- | :--- |
| 대상&nbsp;모델 | 8개 계열 12종: Llama‑3.1‑8B, Llama‑3.2‑3B, Mistral‑7B, Falcon3‑7B, Granite‑3.1‑2B, DeepSeek‑7B, GLM‑4‑9B, Qwen2.5‑1.5B/7B/14B, Gemma‑2‑9B/27B |
| 규모 | 1.5B\~27B(15억\~270억) 파라미터, 은닉 차원 1,536\~5,120 |
| 평가&nbsp;자료 | 20개 모델 쌍, 16개 관계(수도, 저자 등)에 걸친 8,800개 사실(주어와 정답 쌍) |
| 자료&nbsp;분할 | 양쪽 모델이 단독으로 맞히는 사실만 사용해 주어 기준으로 학습, 검증, 테스트 분할 (학습 사실 5,000개 미만) |

연구진은 학습 세트에서 회전 행렬과 스케일을 계산한 뒤, 은닉 상태를 교체했을 때 수혜 모델이 공여 모델의 정답을 가장 높은 비율로 생성하는 레이어 쌍($\ell_A, \ell_B$)을 검증 세트에서 선택하고, 학습과 검증에 쓰지 않은 테스트 세트에서 최종 전이 정확도를 평가했다.

![20개 모델 쌍의 테스트 사실 전이 정확도 분포와 6개 대안 매핑 기법의 통계적 유의성 비교 차트](https://img.seosoyoung.eiaserinnys.me/images/platos-key/fig2-transfer-accuracy.png)
*20개 모델 쌍의 전이 정확도 비교(원문 Figure 2). (a) 점 하나가 모델 쌍 하나이며 세로선은 중앙값이다. (b) 동일 교체 레이어에서 각 매핑 기법이 프로크루스테스 회전보다 유의하게 우수한 쌍(파란색), 차이 없는 쌍(회색), 열등한 쌍(붉은색)의 수(Holm 보정 $p < 0.05$). 출처: Hazy Research*

첫째, 회전 변환은 20개 모델 쌍에서 **중앙값 41%**(범위 34\~46%)의 테스트 전이 정확도를 달성했다. 모델 간 변환이 필요 없는 기준선인 자가 교체(self-swap)[^self-swap]의 중앙값은 55%다. 단순 회전만으로 이 정확도를 보존한 비율은 **중앙값 73%**(범위 60\~93%)다. 이 보존율은 계열이 서로 다른 모델 쌍(중앙값 75%)과 같은 계열의 모델 쌍(중앙값 69%)에서 비슷했고, 11개 대조군의 최고 성적은 2.2%에 불과했다.

[^self-swap]: 자가 교체는 수혜 모델 단일 네트워크 내부의 레이어 $\ell_B$에서 "Germany"의 키를 자기 자신이 생성한 "France"의 키로 교체하는 실험이다. 문맥의 나머지 토큰과 다른 레이어에도 여전히 "Germany"에 관한 정보가 남아 있어서, 같은 모델 내부에서 교체해도 답변이 바뀌는 비율은 중앙값 55%다.

둘째, 자유도가 더 큰 매핑 기법들도 회전 변환보다 정확도가 높은 경우는 드물었다. 비교 대상은 스케일 재조정 없는 릿지 회귀(ridge regression), 백색화 회전(whitened rotation), 학습된 다층 퍼셉트론(trained MLP)이다. 동일한 교체 레이어($\ell_A, \ell_B$)에서 이들이 프로크루스테스 회전보다 유의하게 높은 정확도를 기록한 경우는 전체 비교의 7%에 그쳤다.

| 비교 매핑 기법 | 회전보다 우수 | 유의한 차이 없음 | 회전보다 열등 |
| :--- | :---: | :---: | :---: |
| 스케일 재조정 릿지 회귀 | 4쌍 | 13쌍 | 3쌍 |
| 백색화 회전 | 2쌍 | 13쌍 | 5쌍 |
| 학습된 MLP | 1쌍 | 8쌍 | 11쌍 |
| 일반 릿지 회귀 | 1쌍 | 8쌍 | 11쌍 |
| 최소제곱 스케일 회전 | 0쌍 | 7쌍 | 13쌍 |
| 바서슈타인 프로크루스테스 | 0쌍 | 4쌍 | 16쌍 |

릿지 회귀에 스케일 재조정을 추가하면 회전과 대등해지는 반면, 회전 행렬에 최소제곱 스케일을 결합하면 단 한 쌍에서도 성능이 개선되지 않았다. 수혜 모델 고유의 은닉 상태 분산 규모를 보존해야 전이가 제대로 작동하는데, 최소제곱 적합은 이 스케일을 과소추정하기 때문에 성능이 낮아진다. 짝지은 사실 데이터 없이 분포만 정렬하는 바서슈타인 프로크루스테스도 기본 회전 정확도의 중앙값 87%를 기록했다.

셋째, 기하학적 유사성이 높다고 해서 기능적 전이가 잘 일어나는 것은 아니었다. PRH 원 논문의 주 지표인 상호 최근접 이웃 유사도(mKNN)를 기준으로 교체 레이어를 선택하면 동일 검증 세트의 전이 정확도가 <strong>중앙값 4.5%</strong>까지 낮아지는데, 이 수치는 검증 세트 전이 정확도를 기준으로 레이어를 선택했을 때와 비교해 약 10분의 1 수준에 그친다. mKNN은 수혜 모델 전체 깊이의 첫 5% 이내에서 가장 높지만, 기능적 전이 정확도는 모델 깊이의 **22\~38% 구간**에서 가장 높기 때문이다.

## 회전의 연쇄와 256차원 주성분 압축

모델 쌍마다 따로 정렬할 수 있다면, 모든 LLM이 하나의 기하 구조를 공유하는지도 검증할 수 있다. 단일한 기저 구조를 공유한다면 세 모델 $A, B, C$를 순서대로 잇는 연쇄 회전($A \to B \to C$)이 직접 회전($A \to C$)만큼 잘 작동해야 하고, 원래 은닉 차원보다 낮은 차원에서도 전이가 유지되어야 한다.

![Gemma, Llama, Qwen 세 모델의 주어 표현 분포가 회전과 스케일 변환으로 정렬되고 하나의 저차원 구조를 공유함을 보여주는 개념도](https://img.seosoyoung.eiaserinnys.me/images/platos-key/fig3-chaining-compression-concept.png)
*회전 연쇄와 차원 압축 개념도(원문 Figure 3). 세 원반은 Gemma(모델 A), Llama(모델 B), Qwen(모델 C)의 표현 공간이며, 가운데 구는 회전과 스케일 변환으로 정렬된 공유 저차원 구조를 나타낸다. 출처: Hazy Research*

연쇄 회전 실험에서는 직접 변환($A \to C$)을 쓰지도, 중간 모델 $B$를 실제로 실행하지도 않았다. 개별로 구한 $(A \to B)$ 변환과 $(B \to C)$ 변환을 수학적으로 합성했다. 이때 $(A \to B)$의 수혜 레이어는 $(B \to C)$의 공여 레이어와 일치시켰으며, 세 모델이 모두 단독으로 맞히는 테스트 사실에서 양 끝단 레이어를 동일하게 두고 직접 회전과 비교했다.

![47개 연쇄 회전 경로의 직접 회전 대비 정확도 유지율과 주성분 개수별 상대 전이 정확도 차트](https://img.seosoyoung.eiaserinnys.me/images/platos-key/fig4-chaining-pca-results.png)
*연쇄 회전 및 압축 회전의 전이 정확도(원문 Figure 4). (a) 점 하나가 연쇄 경로($A \to B \to C$) 하나이며 세로 실선은 중앙값, 점선은 직접 회전($A \to C$), 회색 영역은 직접 회전 정확도의 95% 이상 구간이다. (b) 유지한 상위 주성분 수에 따른 상대 전이 정확도의 중앙값과 사분위 범위(붉은 음영). 출처: Hazy Research*

총 47개 연쇄 경로를 측정한 결과, 연쇄 회전은 직접 회전 전이 정확도의 <strong>중앙값 99%</strong>를 유지했다. 47개 경로 중 40개가 직접 회전 정확도의 95% 이상을 보존했고, 92% 미만으로 감소한 경로는 단 하나도 없었다.[^chaining-over100]

[^chaining-over100]: 일부 연쇄 경로(예: Gemma‑2‑27B $\to$ Llama‑3.1‑8B $\to$ Llama‑3.2‑3B 경로는 103.4%)에서는 중간 모델을 거친 합성 회전이 직접 구한 회전보다 소폭 높은 테스트 정확도를 기록하기도 했다.

차원 압축 실험에서는 각 LLM의 원래 은닉 차원(1,536\~5,120차원)을 상위 주성분(principal components)으로 축소해 회전 변환을 구하는 한편, 축소 과정에서 제외된 수혜 모델의 나머지 주성분에는 학습 데이터의 평균값을 대입했다.

| 상위 주성분 | 상대 정확도 | 사분위 범위 |
| :---: | :---: | :---: |
| 16개 | 4% | 3\~4% |
| 32개 | 13% | 11\~16% |
| 64개 | 35% | 30\~38% |
| 128개 | 57% | 52\~62% |
| **256개** | **74%** | **70\~81%** |
| 512개 | 87% | 80\~89% |
| 1,024개 | 90% | 87\~94% |

상위 256개 주성분을 유지하면 전체 차원 회전 정확도의 <strong>중앙값 74%</strong>가 보존되며, 256개부터는 차원을 늘려도 정확도 증가 폭이 완만해진다. 따라서 모델 쌍마다 개별 변환 행렬을 따로 구하지 않더라도, 각 모델에서 하나의 공유 저차원 공간으로 매핑하는 회전 행렬 하나씩만 구하면 표현을 서로 교환할 수 있다.

## 다른 모델의 회전된 키로 복원하는 암흑 기억

LLM이 학습한 지식을 가중치 내부에 보유하고 있으면서도 직접 질문에는 정답을 인출하지 못하는 현상이 선행 연구[^dark-prior]에서 확인된 바 있는데, Hazy Research는 이런 지식을 **암흑 기억**(dark memories)이라 부른다. 연구진은 공유 기하 구조를 이용해, 수혜 모델이 인출에 실패한 기억을 다른 모델의 회전된 키로 복원할 수 있는지 검증했다.

[^dark-prior]: Song et al. (2025, arXiv:2503.15299) 등, LLM이 학습 데이터에서 습득해 내부에 보유하고 있으나 기본 디코딩 경로에서 인출에 실패하는 잠재 지식을 다룬 연구를 가리킨다.

예를 들어 영화 《인터스텔라(Interstellar)》의 감독을 묻는 프롬프트에서, 수혜 모델은 자체 생성한 "Interstellar" 키로 가중치를 조회하다가 잘못된 항목인 데니 빌뇌브(Denis Villeneuve)와 강하게 결합해 오답을 출력한다. 이때 정답을 아는 공여 모델의 "Interstellar" 키에 회전과 스케일 변환을 적용해 수혜 모델에 주입하면, 수혜 모델의 가중치에 저장되어 있던 정답 크리스토퍼 놀란(Christopher Nolan)이 인출된다.

![수혜 LLM이 자체 키로는 Interstellar 감독을 Denis Villeneuve로 오답 인출하지만 공여 LLM의 회전된 키를 주입하면 가중치 속 암흑 기억인 Christopher Nolan을 정확히 인출하는 도식](https://img.seosoyoung.eiaserinnys.me/images/platos-key/fig5-unlocking-dark-memory.png)
*암흑 기억 복원 도식(원문 Figure 5). 왼쪽 공여 모델의 키를 회전과 스케일 변환($sR$)해 가운데 수혜 모델의 키로 교체하면, 자체 키가 놓쳤던 가중치 내 암흑 기억 행(붉은 테두리)이 선택되어 오른쪽 정답으로 출력된다. 출처: Hazy Research*

연구진은 20개 모델 쌍의 테스트 사실 중 공여 모델은 직접 프롬프트에서 맞히지만 수혜 모델은 틀린 사례(misses) 2,600건을 수집했다. 그리고 수혜 모델이 다음 세 가지 검사 중 하나라도 통과하면, 그 지식이 가중치에 있는 암흑 기억으로 분류했다.

1. **인컨텍스트 예시 제시**: 동일 관계의 예시(in-context examples) 3개를 함께 주었을 때 정답을 생성하는 경우
2. **프롬프트 패러프레이즈**: 질문 문장을 다른 표현으로 바꾸어 물었을 때 정답을 생성하는 경우
3. **동일 관계 내 후보 순위**: 같은 관계에 속하는 최대 50개 후보 답안 중 정답의 생성 확률이 가장 높은 경우

검사 결과, 수혜 모델이 틀린 2,600건 중 절반 이상인 **56%**(1,463건)가 가중치 내부에 지식이 저장된 암흑 기억으로 확인됐다. 가중치를 전혀 수정하지 않은 채 공여 모델의 회전된 키로 바꿔 넣었을 때 암흑 기억 1,463건 중 **18%**(267건)가 정답으로 복원된 반면, 무작위 회전 등 대조군 변환의 복원율은 모두 1.1% 이하로 집계됐다. 이 결과로부터 사실 인출 실패의 상당수가 가중치 내부의 지식 결여가 아닌, 초기부터 중간까지의 레이어가 유효한 조회용 키 표현을 구성하지 못한 현상에서 비롯됨을 알 수 있다. 단순한 좌표계 변환으로 다른 모델의 키를 대입하면 이 잠재된 지식을 인출할 수 있다.

## 단일 표현 공간 정렬과 향후 연구 방향

연구진은 닫힌 형태의 회전과 단일 스케일만으로 LLM 간 사실 인출 표현이 호환된다는 결과를 플라톤적 표현 가설(PRH)에 대한 **기능적 증거**(functional evidence)로 해석한다. 서로 다른 모델의 표현은 기하학적으로 닮은 데 그치지 않고 실제로 교체 가능한 부품처럼 작동한다. 트랜스포머의 MLP 층을 헤비안 메모리(Hebbian memories)[^hebbian]로 해석해 온 Hazy Research의 기존 관점에 비추어 보면, 한 LLM의 회전된 키가 다른 LLM의 가중치 메모리를 직접 질의(query)하는 셈이다.

[^hebbian]: Hazy Research가 2026년 7월 22일 발표한 블로그 연구 글 "MLPs are Hebbians"에서 제시한 관점으로, 트랜스포머의 MLP 가중치를 연상 메모리(associative memory)로 해석한다.

![12개 베이스 LLM 각각의 표현 공간을 일반화 프로크루스테스 분석으로 동시에 회전 및 스케일 변환해 하나의 공유 좌표계로 정렬하는 개념도](https://img.seosoyoung.eiaserinnys.me/images/platos-key/fig6-shared-representation-space.png)
*12개 LLM의 단일 표현 공간 정렬 개념도(원문 Figure 6). 12개 베이스 모델이 각자 회전되고 스케일이 다른 사실 분포를 갖고 있을 때, 모델마다 하나의 회전과 스케일을 동시에 구하면 모든 모델의 대응 표현(예: 붉은 점 France)이 하나의 공유 좌표계에서 일치한다. 출처: Hazy Research*

연구진은 이번 실험을 바탕으로 두 가지 후속 연구 과제를 제시한다.

- **공유 기하 구조의 확장성 검증**: 12개 모델을 하나의 보편 표현 공간에 동시에 정렬할 수 있는지 확인한다. 또 단발성 사실 인출 외에 다단계 추론(multi-hop reasoning), 사후 학습(post-trained) 모델, 더 큰 규모의 모델, 다른 모달리티에서도 동일한 회전 호환성이 성립하는지 탐구한다.
- **효율적인 다중 모델 시스템 구축**: 재학습 없이 모델 간에 지식을 이식하거나 서로 다른 모델이 은닉 상태를 재사용해 추론 비용을 절감하는 방법, 그리고 자연어 토큰으로 디코딩하는 대신 잠재 표현인 뉴럴리즈(Neuralese)로 모델끼리 직접 통신하는 아키텍처를 설계한다.

## 가장 흥미로운 지점

이 실험에서 특히 주목할 대목은 두 레이어의 깊이가 전혀 다르다는 점이다. 기하학적 유사도 지표인 mKNN이 최고치를 기록하는 레이어는 전체 깊이의 첫 5% 이내이고, 실제 기능적 전이가 작동하는 레이어는 깊이의 22\~38% 구간이다. 입력 임베딩 직후의 얕은 층에서는 토큰의 표면 정보가 유지되므로 모델 간 이웃 구조가 서로 비슷하게 나타나지만, 이 단계의 은닉 상태만으로는 다른 모델의 후기 레이어를 구동해 정답을 인출하기 어렵다(전이 정확도 4.5%). 주어 토큰이 사실 조회용 키로 압축되는 중간 레이어에 이르러서야, 닫힌 형태의 회전 행렬 하나로 다른 모델의 가중치 메모리를 정확히 조회할 수 있다.

수혜 모델이 직접 프롬프트에서 답하지 못한 사실의 56%가 가중치 내부에 이미 저장된 암흑 기억이었다는 결과도 눈여겨볼 만하다. 가중치를 수정하지 않고 공여 모델의 회전된 키만 대입했는데도 그중 18%가 정답으로 복원됐다. 원래 1,536\~5,120차원인 은닉 상태를 상위 256개 주성분으로 압축하고 세 모델을 연쇄로 이어도 전이 정확도가 유지된다면, 서로 다른 LLM이 각자 하나의 공유 256차원 좌표계로 매핑하는 회전 행렬만 갖춘 구조를 구상해 볼 수 있다. 이 구조에서 모델들은 자연어 문장 대신 압축된 잠재 키 벡터를 주고받으며 서로의 기억 인출 실패를 보완하게 된다.
