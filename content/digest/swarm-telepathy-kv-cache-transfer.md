## 3줄 요약

1. MIT CSAIL과 MIT-IBM 컴퓨팅 연구소 공동 연구진이 2026년 10월에 공개한 논문이다. 연구진이 제안한 SwaT(Swarm Telepathy)는 아키텍처와 토크나이저가 서로 다른 LLM 계열 사이에서 수신 모델이 원문 텍스트를 다시 프리필[^prefill]하지 않고도 송신 모델의 KV 캐시[^kv-cache]를 직접 변환해 이어받게 한다.
2. 송신 모델과 수신 모델의 가중치는 동결한 상태로 두고, 그 사이를 잇는 약 3억 개 파라미터 규모의 트랜스포머 매퍼만 따로 학습한다. 학습에는 영어 텍스트 4,400만 토큰과 GPU 1일(1 GPU-day) 미만의 연산이 든다. 토크나이저가 달라서 생기는 불일치는 문자 인덱스 구간(character span)을 기준으로 회전 위치 임베딩(RoPE)을 선형 보간하고 인과 마스킹을 적용해 해소한다.
3. 6개 모델 계열의 12개 LLM과 17개 벤치마크에서, 변환된 캐시를 받은 수신 모델은 단독 성능의 92.2\~143.2%를 유지했다. KV 캐시 압축 기법인 Attention Matching과 결합해 에이전트 사이의 통신에 쓰면, 텍스트 요약을 전달할 때보다 평균 점수가 40% 이상(기하평균 기준 48.8%) 높았고 송신 GPU 시간과 수신 첫 토큰 지연 시간은 4배 이상 짧았다. 시각 언어 모델(VLM)의 시각 정보와 중국어 특화 지식도 텍스트 전용 수신 모델에 제로샷으로 전달됐다.

[^prefill]: 프리필(prefill)은 LLM이 입력 프롬프트 토큰 전체를 병렬로 처리해 각 층의 키(Key)와 값(Value) 벡터를 처음 계산하는 단계다. 이후 출력 토큰을 하나씩 생성하는 단계는 디코드(decode)라 부른다.
[^kv-cache]: KV 캐시(Key-Value Cache)는 트랜스포머가 이전 토큰들의 키와 값 텐서를 메모리에 저장해 두어 다음 토큰을 생성할 때 중복 연산을 피하는 내부 상태 데이터다.

## 텍스트 기반 멀티에이전트 통신의 병목과 기존 KV 캐시 전달의 한계

여러 LLM 에이전트가 역할을 분담해 협업하는 멀티에이전트 시스템에서는 거의 예외 없이 자연어 텍스트가 통신 매개체로 쓰인다. 앞선 에이전트가 긴 문서를 읽고 분석한 결과를 요약문으로 작성하면, 다음 에이전트가 그 요약문을 입력으로 받아 자신의 작업을 수행하는 식이다. 어떤 모델끼리든 손쉽게 이어 붙일 수 있다는 장점이 있는 반면에, 통신 대역폭과 연산 효율에서는 두 가지 손실이 생긴다.

첫째는 표현 대역폭의 손실이다. 송신 에이전트는 문서를 처리하는 동안 모든 트랜스포머 층과 모든 토큰의 고차원 내부 표현(KV 캐시)을 이미 계산해 두고 있다. 그러나 이것을 다음 에이전트에 전달할 때는 이산적인 단어 토큰 몇백 개로 압축해 문장으로 출력해야 하므로, 요약문에 채택되지 않은 세부 맥락은 사라진다. 둘째는 중복 연산 비용이다. 송신 에이전트가 요약문을 한 토큰씩 자기회귀(autoregressive) 방식으로 디코딩하는 데 수 초의 GPU 시간이 들고, 수신 에이전트는 전달받은 요약문을 처음부터 다시 프리필해야 자기 추론을 시작할 수 있다.

최근 송신 모델의 KV 캐시를 수신 모델용 KV 캐시로 변환하려는 연구가 여럿 등장했으나, 실제 멀티에이전트 환경에 적용하기에는 제약이 있었다. 기존 방법들은 크게 두 부류로 구분된다. 한 부류는 같은 모델 계열(예: Qwen 3 4B와 Qwen 3 14B)에서 크기만 다른 모델 사이에서만 캐시를 전달할 수 있다[^same-family]. 같은 팀이 같은 토크나이저와 데이터 파이프라인, 증류(distillation) 과정으로 만든 모델들이라 내부 표현 구조가 이미 비슷하다. 나머지 부류의 연구들은 서로 다른 모델 계열 사이의 캐시 변환을 시도했으나, 수신 모델이 원문 텍스트를 함께 프리필해야 작동하므로 프리필 연산 자체를 생략하지는 못한다.

[^same-family]: 같은 모델 계열 내 크기가 다른 모델 사이에 헤드별 리지 회귀로 KV 캐시를 변환한 선행 연구(Heo et al., 2026)의 상세 내용은 서재 다이제스트 [「Cross-Model KV Cache Transfer in LLM Families」](https://seosoyoung.eiaserinnys.me/digest/cross-model-kv-cache-transfer/)에서 다루었다.

연구진은 플라톤적 표현 가설(Platonic Representation Hypothesis, Huh et al., 2024)에 근거를 두었다. 이 가설에 따르면, 서로 다른 조직이 서로 다른 아키텍처와 데이터로 학습한 모델이라도 같은 세계를 학습했다면 내부 표현이 점차 수렴한다. 두 모델이 표현하는 대상의 의미 정보가 본질적으로 공유된다면, 계열 사이의 통신은 송신 모델의 KV 캐시 표현을 수신 모델이 읽을 수 있는 표현 형식으로 변환하는 매핑 함수 $M_{i \rightarrow j}$를 학습하는 문제로 바뀐다.

$$
\widehat{C}_{x}^{(j)} = M_{i \rightarrow j}\bigl(C_{x}^{(i)}\bigr), \qquad y^{(j)} \sim \mathcal{A}_{\mathrm{decode}}^{(j)}\bigl(\widehat{C}_{x}^{(j)}, q\bigr)
$$

수식에서 송신 에이전트 $\mathcal{A}^{(i)}$는 문서 $x$를 한 번 프리필해 캐시 $C_x^{(i)}$를 만들고, 매퍼 $M_{i \rightarrow j}$가 이것을 수신 에이전트 $\mathcal{A}^{(j)}$용 예측 캐시 $\widehat{C}_x^{(j)}$로 변환한다. 수신 에이전트는 원문 $x$를 전혀 읽지 않은 채 변환된 캐시와 짧은 질문 $q$만으로 답 $y^{(j)}$를 디코딩한다.

## SwaT 아키텍처와 교차 토크나이저 정렬

SwaT는 동결된 송신 모델 $\mathcal{S}$와 수신 모델 $\mathcal{R}$을 연결하며, $B$개 블록으로 이루어진 트랜스포머 매퍼다. 본문 실험에서는 블록 수 $B \in \{7, 8, 9\}$, 은닉 차원 $D = 1024$, 어텐션 헤드 수 $H = 16$, 피드포워드 폭 $F = 4096$을 사용해 학습 가능한 파라미터 수를 약 3억 개(300M)로 맞췄다.

### 층 그룹 분할과 블록 연산

송신 모델과 수신 모델은 트랜스포머 층 수($L_{\mathcal{S}}, L_{\mathcal{R}}$)와 KV 헤드 수($H_{\mathcal{S}}, H_{\mathcal{R}}$), 헤드 차원($\delta_{\mathcal{S}}, \delta_{\mathcal{R}}$)이 모두 다르다. SwaT는 두 모델의 전체 층을 각각 $B$개의 연속된 층 그룹 $\mathcal{S}_b, \mathcal{R}_b$ ($b \in \{0, \ldots, B-1\}$)로 균등 분할한다.

$$
\mathcal{U}_{b} = \left\{\ell : \left\lfloor\frac{bL_{\mathcal{U}}}{B}\right\rfloor \leq \ell < \left\lfloor\frac{(b+1)L_{\mathcal{U}}}{B}\right\rfloor\right\}, \quad \mathcal{U} \in \{\mathcal{S}, \mathcal{R}\}
$$

매퍼는 문서 $d$를 수신 모델의 토크나이저로 토큰화해 시퀀스 $\mathcal{T}_{\mathcal{R}} = (r_0, \ldots, r_{R-1})$을 얻는다. 이 시퀀스를 수신 모델의 동결 임베딩 테이블 $E_{\mathcal{R}}$에서 조회하고(단순 테이블 조회이므로 0 FLOPs), 학습 가능한 입력 행렬 $\underline{W}_{\mathrm{in}} \in \mathbb{R}^{D \times D_{\mathcal{R}}}$을 곱해 초기 은닉 상태 $h_0 \in \mathbb{R}^{D \times R}$를 만든다[^raw-tokens].

[^raw-tokens]: 초기 은닉 상태 $h_0$를 만들 때 수신측 토크나이저로 문서 텍스트를 토큰화하고 임베딩 테이블을 조회하므로 원문 텍스트에 대한 접근 자체는 필요하다. 이 과정은 행렬 곱셈이나 트랜스포머 층을 전혀 거치지 않는 0 FLOPs 조회이며, 수신 모델 본체의 프리필 연산을 완전히 대체한다.
[^sliding-window]: Gemma 2와 3처럼 최근 토큰만 참조하는 슬라이딩 윈도우 어텐션 층은 송신측과 수신측에서 다르게 처리한다. 송신측에 있으면 윈도우에서 제외된 과거 KV 캐시도 버리지 않고 기록해 SwaT 입력으로 전달한다. 수신측에 있으면 SwaT가 전체 토큰 캐시를 예측하고, 수신 모델이 평소대로 오래된 캐시를 버린다.

| 구성 요소 | 입력과 차원 | 수행 연산 | 출력과 역할 |
|---|---|---|---|
| **초기화 모듈** | 수신 토큰열 $\mathcal{T}_{\mathcal{R}}$ (길이 $R$) | 동결 임베딩 조회 $E_{\mathcal{R}}$ (0 FLOPs) 후 선형 투영 $\underline{W}_{\mathrm{in}}$ | 초기 은닉 상태 $h_0 \in \mathbb{R}^{D \times R}$ 생성 |
| **송신 메모리 투영** | 송신 층 그룹 $\mathcal{S}_b$의 KV 캐시 (길이 $S$) | 키(Key)의 송신 RoPE 역회전 제거(de-RoPE), 층과 헤드 연결 후 LayerNorm + $\underline{W}_b^{\mathrm{mem}}$ | 블록 $b$의 교차 어텐션 메모리 $m_b \in \mathbb{R}^{D \times S}$ 생성 |
| **SwaT 블록 $b$** | 은닉 상태 $h_b$와 송신 메모리 $m_b$ | 인과 셀프 어텐션(정수 RoPE) $\rightarrow$ 인과 교차 어텐션(문자 구간 RoPE) $\rightarrow$ GELU FFN | 다음 블록 은닉 상태 $h_{b+1} \in \mathbb{R}^{D \times R}$ 갱신 |
| **수신 캐시 출력 헤드** | 블록 출력 $h_{b+1}$ | LayerNorm + $\underline{W}_b^{\mathrm{out}}$ 투영 $\rightarrow$ 층과 헤드별 RMS 통계 보정 $\rightarrow$ 수신 RoPE 적용 | 수신 층 그룹 $\mathcal{R}_b$의 예측 KV 캐시 출력[^sliding-window] |

### 문자 인덱스 구간 기반 교차 토크나이저 정렬

계열이 다른 두 모델은 어휘집이 달라 같은 문자열을 토큰화해도 토큰 수($S \neq R$)와 토큰 경계가 일치하지 않는다. 선행 연구인 Cache-to-Cache(Fu et al., 2026)는 토큰을 정렬하면서 남는 토큰을 버렸고, 그 탓에 핵심 단어나 수치가 사라지는 정보 손실을 겪었다.

SwaT는 두 모델의 원래 토큰화를 보존하고, 교차 어텐션에서만 원문 문자열의 문자 인덱스 구간(character span)으로 RoPE 각도와 인과 마스크를 정렬한다. 문서 $d$의 문자열에서 송신 토큰 $s_i$의 문자 구간을 $[a_i^{\mathcal{S}}, b_i^{\mathcal{S}})$, 수신 토큰 $r_j$의 문자 구간을 $[a_j^{\mathcal{R}}, b_j^{\mathcal{R}})$라 하자. 송신 토큰의 중심점은 $m_i = (a_i^{\mathcal{S}} + b_i^{\mathcal{S}}) / 2$이다. 수신 토큰 중 $a_j^{\mathcal{R}} \le m_i$를 만족하면서 인덱스가 가장 큰 $j$를 기준으로, 교차 어텐션 RoPE 인덱스 $p_i$를 선형 보간한다.

$$
p_{i} = \max\!\left(0,\, j + \operatorname{clip}_{[0,1]}\!\left(\frac{m_{i} - a_{j}^{\mathcal{R}}}{b_{j}^{\mathcal{R}} - a_{j}^{\mathcal{R}}}\right) - \frac{1}{2}\right)
$$

두 토크나이저가 같다면 모든 문자 구간이 일치해 $p_i = i$가 된다. 인과 마스킹(causal masking)도 문자 경계를 기준으로 삼는다. 수신 토큰 $r_j$는 송신 토큰의 끝 문자 인덱스가 자신의 끝 문자 인덱스 이하인 경우($b_i^{\mathcal{S}} \le b_j^{\mathcal{R}}$)에만 그 송신 토큰을 참조한다. 이 제한으로 나중에 나오는 텍스트의 정보가 앞선 토큰에 반영되는 일을 막는다.

### 2단계 학습 목적 함수와 절제 실험

학습은 중복을 제외한 영어 토큰 4,400만 개 데이터(bf16 정밀도, AdamW, 가중치 감쇠 $10^{-3}$)를 사용해 두 단계를 차례로 진행한다.

| 학습 단계 | 목적 함수 | 스텝 수와 학습률 | 학습 데이터 구성 |
|---|---|---|---|
| **1단계 (캐시 복원)** | 수신 모델 실제 캐시 $C_d^{\mathcal{R}}$와 예측 캐시 간 RMS 정규화 평균제곱오차($\mathcal{L}_{\mathrm{KV}}$, RoPE 적용 전) | 5,000스텝<br>코사인 (최댓값 ${3 \times 10^{-4}}$) | PG-19, WikiText-103, QASPER, QuALITY, HotpotQA, MuSiQue 학습 분할 |
| **2단계 (생성 정렬)** | 변환된 캐시와 질문 $q$로 동결 수신 모델이 정답 $y$를 생성할 때의 다음 토큰 예측 손실($\mathcal{L}_{\mathrm{NLL}}$) | 24,000스텝<br>고정 (${3 \times 10^{-6}}$) | 1단계 데이터, ARC-C, HellaSwag, WinoGrande, MMLU, GSM8K 추론 과정 |

2단계에서는 기울기(gradient)가 동결된 수신 모델을 통과해 SwaT 매퍼에 전달되고, 갱신되는 것은 매퍼 파라미터뿐이다.

| 절제 실험 항목 (Qwen 3 4B $\rightarrow$ Llama 3 8B, 13개 벤치마크 평균) | 기본 SwaT 대비 점수 변화 (%p) |
|---|---:|
| **기본 SwaT (2단계 학습, 문자 구간 토크나이저 정렬, 트랜스포머 매퍼)** | **0.00** |
| Cache-to-Cache 방식의 토큰 정렬로 교체 | -3.20 |
| 트랜스포머 매퍼를 헤드별 MLP(Headwise MLP)로 교체 | -14.71 |
| 1단계(KV 캐시 MSE 손실)만 학습 | -36.97 |
| 2단계(다음 토큰 예측 NLL 손실)만 학습 | -36.96 |
| 밀집 은닉 상태 복원 손실(Dense loss)만 학습 | -55.11 |

위 절제 실험 표(논문 부록 E의 표 18)를 확인하면 왜 두 학습 단계를 모두 거쳐야 하는지가 드러난다. 1단계 캐시 복원만 수행하거나 2단계 생성 손실만으로 학습하면 13개 벤치마크 평균 점수가 각각 36.97%p, 36.96%p 하락한다. 1단계에서 매퍼의 출력이 수신 모델의 캐시 분포와 비슷해지도록 먼저 초기화해야 2단계의 미세한 생성 정렬이 수렴하기 때문이다. 또한 교차 어텐션 트랜스포머 대신 토큰과 헤드 단위의 MLP만 쓰면 토큰 경계 차이를 처리하지 못해 점수가 14.71%p 떨어진다.

## 6개 모델 계열 간 KV 캐시 전달 유지율

첫 번째 본 실험은 유지율(retention, %)을 측정한다. 유지율은 수신 모델이 원문 텍스트를 직접 읽었을 때의 점수($\text{score}_{\text{receiver}}$)에 대한, 송신 모델이 읽은 KV 캐시를 SwaT로 변환해 받았을 때의 점수($\text{score}_{\text{SwaT}}$)의 비율이다. Qwen 3, Llama 3와 3.2, Gemma 2와 3, Ministral 3, Granite 3.3, SmolLM3의 6개 계열(3B\~32B)에서 서로 다른 계열끼리 짝지은 모델 쌍 10개를 구성했다. 평가에는 학습에 쓴 분포의 벤치마크 9개(In-domain)와 학습 때 보지 못한 분포의 벤치마크 8개(OOD), 모두 17개를 썼다.

Granite 3.3 8B의 캐시를 전달받은 SmolLM3 3B는 평균 유지율 143.2%를 기록했다(학습 분포의 장문 F1에서는 253.6%).

## 텍스트 요약(T2T) 대 KV 캐시 압축 전달(SwaT + AM)

실제 멀티에이전트 시스템에서는 송신 에이전트의 긴 문맥 전체를 그대로 전달하면 수신 에이전트의 디코딩 비용이 커지고 불필요한 중간 추론 흔적이 문맥의 품질을 해친다. 이 때문에 텍스트 통신(T2T)에서는 송신 에이전트가 핵심 내용을 요약문 $s$로 줄여서 보낸다. KV 캐시 통신에서는 SwaT로 변환한 캐시를 Attention Matching(AM, Zweiger et al., 2026)[^am]으로 압축해 보낸다(SwaT + AM).

[^am]: Attention Matching(AM)은 경량 KV 캐시 압축 기법이다. 원래의 전체 KV 캐시가 어텐션 출력에 미치는 영향을 최대한 보존하면서 키와 값의 개수를 목표 예산 $U$개로 줄인다.

연구진은 공정한 비교를 위해 송신 에이전트에게 길이가 다른 5가지 요약 프롬프트를 주어 T2T 요약문의 토큰 길이를 측정한 뒤, SwaT + AM의 유지 캐시 예산 $U$를 해당 요약문의 수신측 토큰 수 이하가 되도록 맞췄다. 7개 장문 데이터셋(QuALITY, QASPER, HotpotQA, MuSiQue, SQuAD, NarrativeQA, LongHealth)과 5가지 압축 예산, 3개 모델 쌍에 대해 측정한 평균 점수와 지연 시간을 아래 표(논문 표 3과 부록 표 17)에 정리했다.

| 16K | 299.07 / **22.40** (×13.3) | 1,054.5 / **131.4** (×8.0) | 542.89 / **22.71** (×23.9) | 1,912.0 / **134.9** (×14.2) |
| 64K | 2,040.71 / **247.94** (×8.2) | 7,966.4 / **1,296.3** (×6.1) | 3,490.98 / **249.18** (×14.0) | 13,465.7 / **1,314.9** (×10.2) |

위 표(논문 표 6)는 수신 모델이 원문을 처음부터 다시 프리필하는 비용과 SwaT 매퍼의 연산 비용을 시퀀스 길이별로 비교한 결과다. 약 3억 개 파라미터 규모의 SwaT 매퍼는 8B와 14B 수신 모델의 재프리필보다 모든 시퀀스 길이에서 연산 비용이 훨씬 낮다. 특히 수신 모델이 8B에서 14B로 커지면 재프리필의 연산량과 지연 시간은 약 1.7\~1.9배로 늘지만, SwaT 매퍼의 연산 비용은 거의 그대로여서 대형 수신 모델일수록 절감 배율이 커진다.

## 영어 텍스트만 학습한 매퍼의 제로샷 능력 전이

SwaT 매퍼는 오직 영어 텍스트 데이터(4,400만 토큰)로만 학습되었다. 논문은 학습 데이터에 전혀 없던 세 가지 능력, 즉 시각(vision) 이해, 외국어(중국어) 지식, 수신 모델의 최대 문맥 길이를 초과하는 장문 처리가 KV 캐시를 통해 제로샷으로 전달되는지 검증했다.

### 1. 시각 언어 모델(VLM)에서 텍스트 전용 LLM으로의 시각 전이

Gemma 3 VLM(4B, 12B)을 송신 에이전트로, 이미지를 전혀 입력받을 수 없는 텍스트 전용 LLM(Granite 3.3 8B, Llama 3 8B, Qwen 3 4B)을 수신 에이전트로 연결했다. 송신 VLM이 이미지 $I$를 보고 짧은 캡션 $P$를 생성할 때, T2T 방식에서는 수신 LLM이 텍스트 캡션 $P$만 읽고 질문 $q$에 답한다. 반면 SwaT 방식에서는 송신 VLM이 이미지와 캡션을 이어 붙인 $I \| P$를 프리필하면서, 이미지 정보가 반영된 캡션 구간 $P$의 KV 캐시를 추출해 SwaT로 텍스트 전용 수신 LLM에 전달한다.

| 모델 쌍과 방식 | 5개 일반 VQA 평균 | DocVQA (고밀도 문자) | InfoVQA (고밀도 문자) |
|---|---:|---:|---:|
| **Gemma 3 4B**<br>**→ Granite 3.3 8B** | | | |
| VLM 단독 | 34.2% | **73.3%** | **41.6%** |
| T2T (캡션) | 21.1% | 39.3% | 25.5% |
| **SwaT (KV 캐시)** | **41.6%** | 43.4% | 31.5% |
| **Gemma 3 4B**<br>**→ Llama 3 8B** | | | |
| VLM 단독 | 34.2% | **73.3%** | **41.6%** |
| T2T (캡션) | 13.3% | 38.4% | 26.6% |
| **SwaT (KV 캐시)** | **39.6%** | 43.3% | 28.6% |
| **Gemma 3 12B**<br>**→ Qwen 3 4B** | | | |
| VLM 단독 | 27.9% | **78.1%** | **46.3%** |
| T2T (캡션) | 29.1% | 48.1% | 29.3% |
| **SwaT (KV 캐시)** | **34.2%** | 35.1% | 23.0% |

5개 일반 시각 질의응답(VQA: VQAv2, TallyQA, OK-VQA, GQA, VizWiz) 벤치마크 평균에서 SwaT는 세 모델 쌍 모두 T2T 캡션 전달보다 높은 점수를 기록했을 뿐 아니라, 이미지를 직접 본 송신 VLM 단독 응답보다도 5.4\~7.4%p 높은 정확도를 냈다. 송신 VLM이 쓴 캡션 문장에는 적히지 않은 시각적 단서가 캡션 토큰의 KV 캐시에는 어텐션을 통해 반영되어 있다. SwaT가 이 잠재 정보를 수신 LLM의 추론 능력과 결합한 결과다[^vqa-ablation]. 반면 위 표의 오른쪽 두 열(논문 부록 표 21)에 수록된 DocVQA와 InfoVQA처럼 이미지 속의 빽빽한 글자와 미세한 표 수치를 직접 읽어야 하는 과제에서는 송신 VLM 단독 응답(평균 57.4%\~62.2%)이 SwaT(29.0%\~37.5%)보다 훨씬 높았다. 캡션 토큰에 간접 반영된 KV 캐시만으로는 고해상도 문자 판독에 필요한 세밀한 시각 정보 전체를 온전히 전달하지 못한다.

[^vqa-ablation]: 논문 부록 표 20에서 송신과 수신을 같은 Gemma 3 4B로 둔 대조군 실험을 보면, SwaT 매퍼를 거쳤을 때 5개 일반 VQA 평균이 34.2%에서 37.4%로 3.2%p 상승했다. 이 상승은 매퍼 학습에 쓰인 질의응답 데이터가 형식 적응을 일부 돕는다는 뜻이다. 그러나 Gemma 3 4B $\rightarrow$ Granite 3.3 8B(41.6%)와 Gemma 3 4B $\rightarrow$ Llama 3 8B(39.6%)에서는 상승 폭이 이보다 크다. 이는 수신 언어 모델의 추론 능력이 결합된 효과가 실제로 작동함을 보여준다.

### 2. 외국어(중국어) 특화 지식 전이와 문맥 한계 확장

중국어 학습 비중이 높은 Qwen 3 4B는 중국어 종합 벤치마크인 CMMLU(67개 과목)에서 Llama 3 8B보다 평균 18.5%p 높은 점수를 기록한다. 영어 데이터만으로 학습해 중국어 토큰을 전혀 접하지 못한 SwaT 매퍼라도, Qwen 3 4B가 중국어 문제를 프리필해 만든 KV 캐시를 변환해 Llama 3 8B에 전달하면 두 모델 점수 차이의 약 4분의 3을 회복시킨다.

| 과목 | Qwen 3 4B 단독 (송신) | Llama 3 8B 단독 (수신) | **SwaT (Qwen $\rightarrow$ Llama)** | Llama 단독 대비 상대 향상률 |
|---|---:|---:|---:|---:|
| 예술 | 90.0% | 55.6% | **88.8%** | +59.6% |
| 개념 물리학 | 83.7% | 45.6% | **73.5%** | +61.2% |
| 보안학 | 83.7% | 55.6% | **77.0%** | +38.7% |
| 전문 심리학 | 82.8% | 56.0% | **77.6%** | +38.5% |
| **67개 과목 평균** | **69.7%** | **51.2%** | **65.1%** | **+27.1%** |

중국어 토큰의 표면 형태와 무관하게 송신 모델 내부에서 형성된 개념 표현이 영어 기반 매퍼를 통해서도 수신 모델로 전달된 셈이다. 이어 아래 표(논문 부록 F의 표 19)에는 최대 문맥 길이가 8K 토큰으로 제한된 수신 모델(Llama 3 8B)이 28K 토큰 길이의 문서를 처리하게 만든 실험이 실려 있다.

| 방법 | 처리 길이 | 완전 일치 (EM, %) | 토큰 F1 점수 (%) |
|---|---:|---:|---:|
| Qwen 3 4B<br>단독 | 28K 텍스트 | 20.4% | 36.75% |
| Llama 3 8B<br>앞 8K만 | 8K 텍스트 | 5.4% | 13.32% |
| Llama 3 8B<br>청크별 AM | 5.6K 캐시 | 21.2% | 34.95% |
| **SwaT + AM** | **5.6K 캐시** | **24.8%** | **41.87%** |

32K 문맥을 지원하는 Qwen 3 4B가 28K 문서를 한 번에 프리필하고, 생성된 28K KV 캐시를 8K 단위로 분할했다. 이 조각마다 SwaT + AM으로 변환하고 압축한 뒤, 총 5.6K 길이의 캐시로 이어 붙여 Llama 3 8B에 전달했다. 송신 모델이 28K 전체를 한 번에 프리필한 뒤 캐시를 분할했으므로, 여러 청크에 이어지는 다중 홉(multi-hop) 문맥 의존성이 이미 캐시에 반영된 채로 압축된다. 그 결과 정확도가 송신 모델 단독이나 수신 모델 자체의 청크별 압축보다 높았다.

## 한계와 향후 과제

논문은 6절에서 현재 SwaT 구조가 지닌 세 가지 한계와 후속 연구 방향을 명시한다.

| 한계 영역 | 현재 구조의 제약 | 논문이 제시한 해결 방향 |
|---|---|---|
| **모델 쌍별 매퍼 수 증가** | $n$개 모델 계열 간 모든 방향의 직접 전달을 지원하려면 ${n(n-1)}$개의 개별 매퍼 학습이 필요하다 | 모든 에이전트가 공유하는 공통 잠재 공간(shared latent space)을 두고 입출력 매퍼 $2n$개만 학습한다 |
| **다단계 전달과 캐시 병합** | 송신에서 수신으로의 1회 전달(single handoff)만 검증했으며, 연속 변환이나 복수 캐시 합산 시 열화가 생긴다 | 최근의 다중 KV 캐시 합성(composition) 기법과 SwaT를 결합해 다자간 에이전트 통신으로 확장한다 |
| **잠재 통신의 감사 가능성** | 표면 텍스트에 드러나지 않는 잠재 정보가 캐시에 실려 전달되므로 텍스트 감시만으로 완전히 통제하기 어렵다 | KV 캐시 전달의 효율과 성능을 유지하면서 잠재 상태의 정보 전달과 안전성을 감사하는 기법을 연구한다 |

## 가장 흥미로운 지점

내가 가장 주목한 점은 같은 매퍼로 두 실험이 모두 성립했다는 것이다. 하나는 VLM에서 텍스트 전용 LLM으로 시각 정보를 전달한 실험(논문 표 4)이고, 다른 하나는 중국어 CMMLU 전이 실험(논문 표 5)이다. 매퍼를 훈련할 때는 4,400만 토큰 분량의 영어 텍스트만 사용했기 때문에, 학습 과정에서는 이미지 패치 토큰도 중국어 한자 토큰도 등장하지 않았다. 그럼에도 송신 모델이 이미지나 중국어 문장을 읽고 만든 KV 캐시를 이 매퍼로 변환해 전달하면, 텍스트 전용 수신 모델은 캡션 문장만 읽었을 때보다 훨씬 높은 정확도로 시각 질문에 답할 뿐 아니라 중국어 CMMLU에서도 51.2%에서 65.1%로 향상된 성적을 낸다.

이 결과로 보면 트랜스포머의 중간과 상위 층 KV 캐시에 담기는 벡터는 특정 자연어 어휘나 모달리티에 종속된 기호열이라기보다, 이미 추상화된 의미 구조에 가깝다. 또 서로 다른 모델 계열의 내부 표현은 이 추상화된 의미 수준에서 기하 구조가 일정 부분 동형이다. 그 덕분에 영어 텍스트로만 학습한 3억 개 파라미터짜리 매퍼로도 다른 모달리티와 다른 언어의 의미가 번역되는 셈이다. 이 실험은 멀티에이전트 시스템의 모듈형 구성이 실용적인 연산 비용으로 가능해졌음을 보여준다. 에이전트마다 특화 모델(비전 특화 소형 모델, 장문 독해 모델, 추론 특화 모델)을 쓰더라도, 자연어를 거치지 않고 각 모델의 강점만 잠재 상태로 결합할 수 있기 때문이다.
