## 3줄 요약

1. OpenAI 정렬 연구팀의 Sean Grove의 발표.
2. '명세가 새로운 코드다'라는 선언을 통해 코딩의 미래를 재정의한다.
3. 모델 스펙을 사례로, 명세가 인간과 모델을 동시에 정렬하는 보편적 수단임을 논증한다.

## 명세 = 새로운 코드

코드 작성이 AI에게 위임될수록, 인간이 작성해야 할 것은 '의도의 명세'다.

- 명세는 코드보다 상위의 정본(canonical source)
- 모델 스펙이 인간의 의도를 모델에 전달하듯, 코드 명세가 에이전트에게 의도를 전달
- 명세 품질 = 에이전트 출력 품질

## 가장 흥미로운 지점

OpenAI의 정렬 연구 경험을 소프트웨어 엔지니어링으로 전이한 관점이 독특하다. 'AI 정렬'과 '에이전트에게 코딩 시키기'가 같은 문제라는 통찰.
