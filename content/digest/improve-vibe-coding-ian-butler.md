## 3줄 요약

1. Ian Butler(CEO, Bismouth)가 SM100 벤치마크 결과를 기반으로 vibe coding의 현실적 한계를 데이터로 제시.
2. Rules·context·thinking model 세 축으로 개선 방법을 제안한다.
3. Vibe coding 카테고리의 첫 기준점 영상으로, 감이 아닌 측정에서 출발한다.

## SM100 벤치마크가 보여주는 현실

데이터 기반으로 vibe coding의 한계를 진단:

- 복잡한 태스크일수록 성공률 급락
- 컨텍스트 부족이 실패의 주요 원인
- 모델 성능보다 입력 품질이 결정적

## 3축 개선 프레임워크

- **Rules**: 프로젝트별 규칙을 명시적으로 제공
- **Context**: 관련 파일·문서를 적극적으로 포함
- **Thinking model**: reasoning 모델 활용으로 복잡도 대응

## 가장 흥미로운 지점

~7분의 짧은 발표이나, 벤치마크 데이터라는 객관적 근거에서 출발한다는 점이 이후 vibe coding 논쟁의 기준선을 설정한다.
