## 3줄 요약

1. 일본의 AI 콘텐츠 디렉터 AI動画ラボ(AI 도가 라보, `@aidoga_lab`)가 생성형 AI 동영상 클립 18편을 상용 편집 프로그램 없이 Python 코드로만 조립해 29.5초 분량의 단편 애니메이션 「멘우치(面打ち)」를 완성했다.
2. Suno로 생성한 일본 전통 타악기와 글리치 음악을 북소리와 나머지 소리로 분리해 타점 표를 만들고, 표에 적힌 타점에만 맞춰 화면을 전환하면서 YOLO, Depth Anything, rembg로 검출한 손과 얼굴 영역에 시각 효과를 적용했다.
3. 강한 원색을 쓰면서도 일본 전통 종이인 화지(和紙)의 섬유 무늬와 흰 글자를 선명하게 지키려고 다섯 가지 색 보정 원칙을 적용했다. 흰 영역에는 빛 번짐을 주지 않고, 원래 색이 있는 영역만 채도를 높이며, 중간 밝기만 어둡게 만드는 방식이다.

## 도구 구성: 영상 생성부터 비전 분석과 코드 편집까지

2026년 11월 25일, AI動画ラボ(`@aidoga_lab`)가 X에 29.5초 분량의 애니메이션 「멘우치(面打ち)」를 공개했다[^menuchi]. 이 작품은 일본 전통 가면극 노가쿠(能楽)의 가면인 노멘(能面)을 나무로 깎아 만드는 작업을 다룬다. 제작 과정에서는 타임라인 기반의 상용 영상 편집 프로그램을 전혀 쓰지 않았다. 개별 생성 도구로 원화와 영상 클립을 만든 뒤, 컴퓨터 비전 분석부터 박자 동기화 컷 편집, 글자 합성, 색 보정까지 후반 편집 전 과정을 Python 코드로 처리했다.

[^menuchi]: 멘우치(面打ち, 한자음 면타)는 노가쿠에서 쓰는 목조 가면인 노멘을 만드는 전통 공예 기술을 뜻하고, 그 기술을 가진 장인도 같은 말로 부른다. 공개된 영상 파일은 가로 1280, 세로 720 해상도, 초당 30프레임, 전체 길이 29.55초 분량이며, 본편 편집 구간 855프레임(28.5초) 뒤에 마지막 제자(題字)인 「面打ち」가 약 1초 동안 등장한다.

| 공정 | 사용한 도구 | 역할과 산출물 |
|---|---|---|
| 원화 및 질감 생성 | Codex 이미지 생성 | 캐릭터 설정화, 각 장면의 첫 프레임, 배경 화지(和紙) 질감 생성 |
| 동영상 클립 생성 | Grok (Image-to-Video) | 캐릭터의 연기 장면과 일본 전통 문양이 변화하는 동영상 18편 생성 |
| 3D 가면 모델링 | Blender | 입체 노멘(能面) 에셋 제작 및 렌더링 |
| 제자 서예 글자 | ChatGPT 이미지 생성 | 작품 제자(題字) 이미지 생성 |
| 배경 음악 | Suno | 일본 전통 타악기와 글리치 사운드를 결합한 120 BPM 음악 생성 |
| 객체 검출 및 분리 | YOLO, Depth Anything, rembg | 프레임 내 사물 영역 검출, 깊이(거리) 추정, 피사체 배경 분리 |
| 편집 및 후반 작업 | Python 코드 (편집 소프트웨어 미사용) | 타점 기반 화면 전환, 영역 한정 이펙트, 세로쓰기 명조체 글자 배치, 색 보정 |

정지된 원화와 화지 질감은 Codex 이미지 생성으로 먼저 만들고, 이를 첫 프레임으로 삼아 Grok의 이미지-투-비디오(Image-to-Video) 기능으로 동영상 클립 18편을 만들어 냈다. 여기에 Blender로 렌더링한 3차원 노멘과 ChatGPT로 만든 제자(題字) 글자를 소재로 더했다.

![나무 탁자 위에서 조각도로 가면을 깎는 장면과 YOLO 검출 라벨](https://img.seosoyoung.eiaserinnys.me/images/aidoga-lab-python-beat-video-editing/02-carving-yolo.png)
*조각도로 가면을 깎는 클립(6.10초, 183번째 프레임). 화면 왼쪽 위에는 경과 시간과 프레임 번호, 템포 120 BPM, 타악기 감지 상태(`KICK`, `HAT #`)가 표시되어 있다. 깎아낸 나무 조각 위에는 YOLO 객체 검출 라벨(`Dog 0.41`)이 그려져 있다. 출처: @aidoga_lab X 게시물 영상*

생성한 영상 클립을 코드로 제어하기 위해 컴퓨터 비전 모델 세 가지를 전처리에 동원했다. 객체 검출 모델인 YOLO로는 프레임 안의 손이나 얼굴, 소품의 사각형 좌표를 찾았다. 이미지 한 장으로 깊이를 추정하는 Depth Anything으로는 전경과 배경의 거리 정보를 추출했고, 배경 제거 도구인 rembg로는 캐릭터와 가면의 윤곽선을 분리했다[^vision-fui]. 이렇게 얻은 좌표와 마스크 데이터는 다음 단계인 영역 한정 이펙트의 입력값이 된다.

[^vision-fui]: 실제 영상 프레임을 확인하면 화면 왼쪽 위와 오른쪽 위에 모니터 HUD 형태의 표시가 있다. 경과 시간(`T`), 본편 855프레임 중 현재 프레임(`F`), 템포(`BPM 120`), 마디 번호(`BAR`), 킥과 하이햇 타격 여부, 원본 소스 번호(`SRC`)와 컷 번호(`CUT`)가 여기에 기록되어 있다. 사전 학습된 YOLO 모델은 둥글게 말린 나무 조각을 `Dog 0.41`로, 전통 부채를 `Umbrella 0.91`로 검출했다. 작성자는 이 바운딩 박스와 신뢰도 수치를 지우지 않고 시각 연출 요소로 그대로 노출했다.

## 오디오 타점으로 편집을 제어하는 6단계 구조

클립을 타임라인에 수동으로 배치하는 대신, 오디오 신호가 컷 전환과 시각 효과를 직접 제어하도록 여섯 단계 규칙을 설계했다.

1. **타악기 분리와 타점 표 작성**: Suno로 만든 배경 음악을 북소리(太鼓, 타이코)와 그 외의 악기 소리로 분리한 뒤, 소리가 울리는 시점을 타점(打点)으로 삼아 표에 기록한다.
2. **타점에 맞춘 화면 전환**: 화면은 아무 때나 바꾸지 않고, 앞서 작성한 표의 타점에만 맞춰 전환한다.
3. **1초마다 바뀌는 연출과 중복 배제**: 1초마다 배경 세계와 시각 기법을 바꾸고, 한 번 쓴 연출 방식은 같은 영상에서 다시 쓰지 않는다.
4. **손과 얼굴 영역 한정 이펙트**: 화면 전체에 필터를 덮어씌우지 않고, 비전 모델로 잡아낸 손이나 얼굴의 사각형 영역에만 시각 효과를 적용한다.
5. **결정적 장면의 정지와 세로쓰기 명조체**: 인상을 강하게 남겨야 하는 결정적 장면(決めの場面)에서는 카메라 화각과 피사체 동작을 고정하고 세로쓰기 명조체 글자를 화면에 삽입한다.
6. **화지 질감을 살리는 최종 색 보정**: 마지막 공정에서 전체 색감을 정돈하되 배경에 깔린 화지(和紙)의 섬유 질감이 사라지지 않도록 마무리한다.

![붉은 화지 배경 위 정면 인물의 한쪽 눈 영역에만 시각 효과를 적용한 장면](https://img.seosoyoung.eiaserinnys.me/images/aidoga-lab-python-beat-video-editing/03-region-effect.png)
*10.10초(303번째 프레임, 11번째 컷) 장면. 붉은 화지 바탕에 정면을 보는 인물의 오른쪽 눈 주변 사각형 영역(`眼`, `0589.031`)에만 색 분리와 점묘 효과를 적용했다. 화면 왼쪽에는 세로쓰기 명조체로 「第壱幕(제1막)」이 적혀 있다. 출처: @aidoga_lab X 게시물 영상*

네 번째 규칙인 영역 한정 이펙트는 생성형 AI 영상의 단조로운 화면 전환을 보완한다. 인물의 얼굴 전체와 배경은 원화의 선과 화지 질감을 그대로 유지하고, 검출한 눈 주변과 부채의 사각형 영역에만 고대비 반전과 색상 분리 효과를 걸어 시선을 모은다.

## 강한 색감에서도 화지 질감과 흰 글자를 지키는 5가지 색 보정 규칙

타래의 마지막 게시물은 다섯 가지 색 보정 요령을 따로 다룬다. 붉은색과 검은색처럼 대비가 강한 색으로 화면을 마무리하면서도 화지(和紙) 특유의 섬유 무늬와 흰색 글자가 뭉개지지 않게 지키는 방법이다.

![붉은 화지 바탕 중앙에 흰색 세로쓰기 명조체로 멘우치 주연이 적힌 장면](https://img.seosoyoung.eiaserinnys.me/images/aidoga-lab-python-beat-video-editing/04-red-washi-type.png)
*9.50초 부근의 정지 타이포그래피 장면. 채도가 높은 붉은 바탕 위에서도 화지의 불규칙한 섬유 무늬가 선명하게 남아 있고, 중앙의 흰색 세로쓰기 명조체(「面打 主演」, 멘우치 주연)도 빛 번짐 없이 뚜렷한 외곽선을 유지한다. 출처: @aidoga_lab X 게시물 영상*

| 순서 | 색 보정 규칙 | 피해야 할 현상과 시각적 효과 |
|---|---|---|
| 1 | 넓은 흰 영역에 빛 번짐(블룸, 글로우)이 생기지 않게 한다 | 빛 번짐을 주면 종이 전체에 뿌연 흰 막이 씌워져 화지의 섬유 무늬가 사라진다 |
| 2 | 채도를 높이는 대상은 원래 색이 있는 영역으로 한정한다 | 무채색인 종이 바탕과 흰 글자에는 색을 더하지 않아야 종이 본연의 밝기가 유지된다 |
| 3 | 붉은색은 뭉쳐서 포화되기 직전에 멈춘다 | 적색 채널을 과도하게 올리면 단색 면처럼 뭉개지지만, 포화 직전에 멈추면 붉은 바탕 위에서도 종이 무늬가 남는다 |
| 4 | 어둡게 만드는 영역은 중간 밝기(미드톤)로 한정한다 | 중간 밝기만 낮추고 밝은 영역(하이라이트)은 그대로 보호해야 어두운 분위기에서도 흰 글자와 종이가 탁해지지 않는다 |
| 5 | 검은색(블랙 레벨)은 마지막에 약간만 낮춘다 | 암부를 소폭 낮추는 것만으로 먹물로 인쇄한 종이 같은 긴장감과 선명한 윤곽이 살아난다 |

이 다섯 가지 규칙은 모두 디지털 후처리 중에 종이 질감의 미세한 명암 차이(고주파 디테일)를 잃지 않게 한다. 블룸 효과, 과도한 적색 채도 증가, 하이라이트 억제는 디지털 영상에서 흔히 쓰는 연출이다. 그러나 화지 같은 질감은 밝은 영역의 미세한 밝기 차이에 의존하므로, 이런 연출은 그 질감을 단번에 지워 버린다. 작성자는 원래 색이 있는 영역과 중간 밝기, 가장 어두운 부분만 골라 조정하고 흰 영역의 밝기 범위는 보호했다. 그 결과 강한 색채 대비와 종이 인쇄물의 질감이 한 화면에 함께 남았다.

## 가장 흥미로운 지점

이번 제작기에서 내가 주목한 설계는 컴퓨터 비전 모델 세 가지(YOLO, Depth Anything, rembg)를 생성 영상의 편집 파이프라인에 결합한 방식이다. 생성형 AI가 만든 짧은 영상 클립 여러 편을 그대로 이어 붙이면, 클립마다 화면 전체가 한꺼번에 바뀌어 편집 리듬이 단조로워지기 쉽다. AI動画ラボ는 프레임 전체를 곧바로 전환하는 데 그치지 않았다. 비전 모델로 프레임 안의 손과 얼굴, 부채의 좌표와 깊이를 먼저 추출하고, 그 영역에만 박자에 맞춰 이펙트가 작동하도록 코드를 짰다. 범용 YOLO 모델은 부채를 우산(`Umbrella 0.91`)으로, 깎아낸 나무 조각을 개(`Dog 0.41`)로 잘못 분류했다. 작성자는 그 잘못된 분류가 적힌 바운딩 박스 라벨까지 그래픽 인터페이스의 일부로 삼아 화면의 밀도를 높였다.

화지 질감을 보존하는 다섯 가지 색 보정 원칙을 코드의 파라미터 제약으로 구현한 점도 실용적이다. 영상 편집 프로그램에서 슬라이더로 전체 채도와 대비를 올리면 붉은 배경은 쉽게 포화되고 흰 종이 질감은 탁해진다. 원래 색이 있는 픽셀만 채도를 올리고, 적색 상한을 포화 직전으로 제한하며, 중간 밝기만 낮추고 하이라이트를 고정하는 연산은 픽셀 값을 수식으로 직접 다루는 Python 코드 환경에서 훨씬 일관되게 적용할 수 있다.
