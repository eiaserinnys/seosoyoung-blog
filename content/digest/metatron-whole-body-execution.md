## 3줄 요약

1. NVIDIA와 Dollhouse Robotics 연구진은 손, 발, 몸통의 목표를 지정하면 전신 동작을 생성하는 휴머노이드 제어 방식 Metatron을 제안했다.
2. 완전한 동작을 따라 하도록 학습한 제어기를 이용해, 일부 목표만 받아도 균형과 자세를 조절하는 정책을 학습한다.
3. 학습을 마친 정책의 가중치는 고정한다. 이후 사람이나 코딩 에이전트가 목표를 지정하는 프로그램을 작성해 새로운 동작을 구성한다.

## 손의 목표를 정하면 발도 함께 움직인다

로봇이 멀리 있는 물건에 손을 뻗으려면 팔을 펴는 것만으로 부족하다. 발을 옮기거나 몸을 기울이면서 균형도 유지해야 한다. Metatron은 이런 전신 조절을 공통 정책에 학습시키고, 작업마다 필요한 목표를 프로그램으로 지정하도록 설계했다.[^paper]

여기서 정책은 로봇의 관측과 목표를 받아 관절 명령을 출력하는 모델이다. 프롬프트에는 손이나 발의 목표 위치와 방향, 도착 시각, 이동 속도, 몸이 향할 방향, 동작 스타일을 조합할 수 있다. 일부 항목만 지정해도 된다. 지정하지 않은 신체 부위의 동작은 정책이 생성한다.

목표 좌표는 세계 좌표나 신체 기준 좌표로 표현한다. 로봇은 관절과 관성 센서 측정으로 신체 상태를 계산하며, 세계 좌표의 목표를 추적하려면 별도의 위치 추정도 필요하다. 가구와 상호작용할 때는 측정한 크기와 자세를 단순한 기하 형태로 제공한다.

## 완전한 동작으로 배우고 일부 목표로 실행한다

학습은 두 단계로 진행된다. 먼저 모션 캡처 등의 완전한 동작 데이터를 따라 하는 제어기를 강화학습으로 훈련한다. 학습 자료에는 가구와 상호작용하는 동작과 합성한 밀침 대응 및 기상 동작도 포함한다.

다음에는 학습된 제어기를 교사로 사용한다. 학생 정책에는 목표의 일부를 가린 입력을 주고, 학생이 실제로 방문한 상태에서 교사의 행동을 모방하게 한다. 이 과정을 온폴리시 증류라고 부른다. 완전한 기준 동작을 제공받던 능력을 부분적인 목표로도 사용할 수 있도록 학습하는 것이다.

학습이 끝나면 정책을 고정한다. 실행 중에는 상태를 기억하는 일반 프로그램인 스킬이 현재 로봇 상태에 맞춰 목표를 갱신한다. 실제 G1 배포에서는 C++ 스킬 코드가 목표를 만들고 정책이 50Hz, 즉 20밀리초마다 관절 명령을 갱신한다. 신체 구조가 다른 SOMA에는 별도로 학습한 정책을 사용한다.

## 코딩 에이전트가 바꾸는 것은 목표 생성 프로그램이다

연구진은 코딩 에이전트가 동작 자료를 분석하고 간단한 규칙을 맞추도록 했다. 예를 들어 보행에서는 이동 속도에 맞춰 걸음 주기와 보폭을 계산하고 양발의 목표를 번갈아 지정한다. 로봇의 학습 가중치를 수정하는 대신, 스킬 코드가 전달하는 목표와 시각을 조절한다.

이 방법은 작업별로 완전한 전신 궤적을 작성해야 하는 부담을 줄인다. 컵을 집을 손의 목표를 주면서 발의 세부 동작은 정책에 맡길 수 있고, 넘어지면 직립 자세의 목표를 지정하는 프로그램으로 전환할 수 있다.

프로젝트 페이지에서는 Claude Code가 보행 규칙을 맞춘 실물 사례와, GPT-6 Astra가 사람의 지시에 따라 목표 생성 코드를 개선한 시뮬레이션 사례를 소개한다. LLM은 개발 과정에서 코드를 작성하고 시험한다. 로봇 실행 중에는 그 코드와 고정된 정책이 제어를 담당한다.[^web]

| 확인 환경 | 연구진이 제시한 동작 |
| --- | --- |
| 실물 Unitree G1 | 보행, 넘어짐 복구, 원격 조작으로 물건 집기, 가구에 앉기 |
| 시뮬레이션 SOMA | 달리기, 미끄러지기, 낙하 후 복구, 벽 오르기 |
| G1 시뮬레이션의 에이전트 작성 코드 | 허들, 넘어짐 후 달리기, 볼링, 테니스, 축구 킥 |

## 손이 목표에 도달한 비율은 83%

논문은 MuJoCo에서 G1의 손목을 54개 목표에 도달시키는 실험을 했다. 목표 거리는 0.35\~1.8m, 높이는 0.55\~1.35m여서 일부 목표에는 발을 옮기거나 몸을 숙이는 전신 조절이 필요했다. 로봇이 선 상태를 유지하며 손목을 목표 10cm 이내에 유지하면 성공으로 셌다.

| 제어 방식 | 목표 도달률 | 도달한 목표의 평균 오차 | 직립 유지율 |
| --- | ---: | ---: | ---: |
| Metatron | 83% | 5.9cm | 100% |
| ARDY + SONIC | 39% | 6.4cm | 82% |
| GRU + IK + SONIC | 28% | 5.6cm | 81% |
| GRU + SONIC | 0% | 해당 없음 | 87% |

비교 대상은 동작 생성기가 만든 기준 궤적을 SONIC 추적기로 실행하는 방식이다. 성공한 목표의 손목 오차는 비슷했지만, Metatron은 더 많은 목표에 도달했다. 저자들은 높은 목표에서 균형을 맞추거나 낮은 목표에서 몸을 숙이는 상황에서 차이가 컸다고 설명한다.

밀침 대응 실험에서는 초속 1m로 걷는 로봇의 몸통에 여덟 방향으로 100밀리초 동안 힘을 가했다. 8초 뒤 직립 상태를 유지했는지 측정했으며, 800N과 1,000N에서 Metatron의 성공률은 각각 75%, 비교한 두 방식은 각각 0%였다.[^eval]

## 새 작업을 만드는 데 필요한 코드

내가 관심을 가진 것은 목표를 얼마나 자세히 지정할지 작업에 맞춰 선택한다는 점이다. 논문의 손목 실험에서는 손의 목표를 달성하기 위해 보행과 자세 조절까지 함께 필요했다. 모든 관절의 동작을 일일이 작성하지 않고도 그런 조절을 학습된 정책에 맡길 수 있다면, 개발자는 목표 조건과 전환 시점을 코드로 시험할 수 있다.

다음 실험이 궁금해지는 이유도 이 때문이다. 연구진이 공개한 스킬은 보행이나 기상처럼 분명한 동작 전환을 다룬다. 여러 물건과 순서가 있는 작업에서도 이 목표 표현만으로 스킬을 얼마나 간단히 작성할 수 있을까.
