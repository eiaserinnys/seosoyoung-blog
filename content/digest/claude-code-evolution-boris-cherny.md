## 3줄 요약

1. Boris Cherny (Anthropic, Claude Code 창시자)가 AI Engineer Conference에서 발표.
2. 프로그래밍 역사 50년의 거시적 진화와 Claude Code의 의도적 단순성 철학을 연결한다.
3. "모델은 지수적으로 발전하는데 제품은 따라가지 못한다"는 고백과, "모르기 때문에 단순하게 만든다"는 설계 원칙이 핵심.

## 프로그래밍 50년 진화

- 기계어 → 어셈블리 → 고급 언어 → 프레임워크 → ... → 에이전트
- 각 단계에서 추상화 수준이 올라감
- Claude Code는 이 진화의 최신 단계

## 의도적 단순성의 철학

"모르기 때문에 단순하게 만든다":

- 모델의 미래 능력을 예측할 수 없으므로, 제품에 복잡한 제약을 걸지 않는다
- 도구를 단순하게 유지하면, 모델이 발전할 때 제품도 자동으로 좋아진다
- 하네스의 복잡성 = 기술 부채

## 영상 21과의 관계

영상 21(Jared)이 Claude Code의 내부를 해부했다면, 이 발표는 창시자 시점에서 **왜** 그렇게 만들었는지를 설명하는 유일한 1차 증언이다.

## 가장 흥미로운 지점

~18분의 짧은 발표이나, "모델이 지수적으로 좋아지는데 왜 제품에 복잡성을 넣는가?"라는 질문이 모든 AI 도구 개발자에게 유효하다.
