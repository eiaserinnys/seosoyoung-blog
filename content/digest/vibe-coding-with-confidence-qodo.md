## 3줄 요약

1. Itamar Friedman(Qodo CEO)의 AI Developer Tools Conference 발표.
2. AI 코딩 도구의 세대를 Gen 1.0(자동완성) → 2.0(에이전틱 채팅) → 3.0(SDLC 전역 멀티에이전트 워크플로우)으로 구분.
3. 'Vibe coding with confidence'를 CLI 기반 에이전트 파이프라인 + 조직 베스트 프랙티스 축적으로 달성한다고 주장한다.

## 3세대 진화

- **Gen 1.0**: 자동완성 (Copilot 초기)
- **Gen 2.0**: 에이전틱 채팅 (Cursor, Claude Code)
- **Gen 3.0**: SDLC 전역 멀티에이전트 워크플로우

## Qodo CLI 시연

발표 당일 소프트 런칭한 Qodo CLI로 에이전트 생성·합성·자동화를 시연. 조직의 코딩 표준과 베스트 프랙티스를 CLI에 내장하여 재현 가능한 품질을 추구한다.

## 가장 흥미로운 지점

'confidence'를 개인 역량이 아닌 조직 시스템으로 달성하려는 접근이 차별점이다.
