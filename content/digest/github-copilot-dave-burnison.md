2. 데모 중심으로 Copilot의 다양한 모드(Chat, Edit, Agent)를 시연한다.
3. Tool Specific 시리즈의 22번째 영상으로, 플랫폼 관점의 통합 경험을 보여준다.

## Copilot 제품 라인업

GitHub의 AI 제품 전략:

- **Copilot Chat**: 대화형 코드 지원
- **Copilot Edit**: 인라인 편집 제안
- **Copilot Agent**: 자율적 태스크 수행
- **Copilot Workspace**: 이슈 → PR 자동화

## 가장 흥미로운 지점

개별 기능보다 GitHub 플랫폼 전체에 AI를 통합하려는 전략이 핵심이다. 단독 AI 도구 vs 플랫폼 통합의 경쟁 축을 보여준다.
